# Генетична симуляція спадковості (Мендель)

Навчальна вебсимуляція моногібридного та дигібридного схрещування,
побудована на основі законів Менделя з використанням
ймовірнісної та стохастичної моделі.

Проєкт призначений для використання в шкільній та STEM-освіті
(біологія, генетика, статистика).

---

## 🔬 Наукова основа

Симуляція реалізує класичну менделівську модель спадковості:

- утворення гамет у процесі мейозу;
- випадкове поєднання гамет під час запліднення;
- формування зигот;
- розподіл генотипів і фенотипів.

❗ Жодні пропорції (3:1, 9:3:3:1) не зашиті вручну —  
усі результати виводяться з імовірнісної моделі.

---

## ⚙️ Можливості симуляції

- моногібридне схрещування (1 ген);
- дигібридне схрещування (2 незалежні гени);
- порівняння:
  - теоретичного очікування;
  - результатів стохастичного експерименту;
- керування розміром вибірки (кількість нащадків);
- візуалізація частот генотипів у вигляді стовпчикової діаграми.

---

## 📊 Педагогічна цінність

Симуляція дозволяє продемонструвати, що:

- спадковість має **ймовірнісний характер**;
- при малих вибірках можливі значні випадкові відхилення;
- великі вибірки наближають результат до теорії;
- випадковість є важливим фактором біологічних процесів.

Проєкт підходить для:
- уроків біології;
- демонстрацій;
- STEM-занять;
- самостійних досліджень учнів.
